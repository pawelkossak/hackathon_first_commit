# U-01 — App shell, routes, game store (Zustand), reset

## Built
- `lib/ui/game-store.ts`: Zustand store wrapping the engine API (`createGame`, `resetGame`, `forecast`, `getAvailableCards`, `previewCard`, `playCard`, `getCurrentEvent`, `resolveEvent`, `resolveWeek`, `rewind`, `savePlan`, `advanceAccountClock`). Persists `GameState` in `localStorage` (`pilot_plynnosci_game_state_v1`).
- `components/ui/AppHeader.tsx`: Sticky navigation bar with links to `/mapa`, `/gra/1`, `/podsumowanie`, `/plan`, `/ustawienia`, live week number, "Dane syntetyczne" badge (GM-01), and reset button with confirmation dialog.
- `components/ui/AppFooter.tsx`: Educational footer with challenge info and synthetic data notice.
- `app/layout.tsx`: Root shell layout with header, main container, footer, metadata and Polish language attributes.
- `app/page.tsx`: `/` root landing / campaign overview directing players to `/gra/1` and `/mapa`.
- `app/mapa/page.tsx`: `/mapa` route rendering the Campaign Map (G09) with level 1 active, levels 2–4 locked, and live star counters.
- `app/gra/1/page.tsx`: `/gra/1` route rendering level 1 game board (G10) with live HUD (cash balance, runway days, week, relations, cost of money), storm alert (28 XII deficit and minimum balance), active event card (G11), interactive card hand (G13) with preview panel, rewind action (G20), and advance week action.
- `app/start/page.tsx`, `app/podsumowanie/page.tsx`, `app/plan/page.tsx`, `app/konto/page.tsx`, `app/ustawienia/page.tsx`: Route shells per ARCHITECTURE.md §3 and DEMO-REQUIREMENTS.md.
- Reset functionality (US-08): Clears `localStorage` and restores demo seed with engine `resetGame("demo")`.
