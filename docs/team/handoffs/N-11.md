# Handoff N-11: PWA Service Worker, Opt-in G34 & `/api/push/demo` (30 s)

- **Built:**
  - `public/sw.js`: Service worker dla PWA oraz Web Push z obsługą zdarzeń `push` i `notificationclick` (przenoszących do deep linka `/gra/1?resume=T3`), a także komunikacji przez `postMessage` dla niezawodnego wywoływania przypomnień demonstracyjnych.
  - `app/api/push/subscribe/route.ts`: Route Handler (`POST`, `DELETE`) do rejestracji i usuwania subskrypcji Web Push.
  - `app/api/push/demo/route.ts`: Route Handler (`POST`) planujący próbne przypomnienie demonstracyjne z 30-sekundowym opóźnieniem (D-14), generujący etyczny komunikat („Tydzień 3 czeka. Wrócisz za stery?”) bez promowania produktów bankowych.
  - `lib/reminders/push-client.ts`: Moduł kliencki z bezpiecznym wykrywaniem środowiska przeglądarki, żądaniem uprawnień do powiadomień, rejestracją service workera oraz odliczaniem i fallbackiem do banera powrotu w grze.
  - `components/narrative/PushOptIn.tsx`: Widok opcjonalnego opt-in powiadomień (G34) oferowany po ukończeniu pętli:
    - Wybór kanałów (Przeglądarka Web Push; E-mail oznaczony jako wymagający logowania dla gościa),
    - Przycisk wywołania próby demonstracyjnej na prezentację (30 s) z odliczaniem na żywo,
    - Uczciwe komunikaty stanu (blokada w przeglądarce, zaplanowanie, fallback do banera powrotu),
    - Dostępność: targety ≥ 44 px, kontrast AA, obsługa klawisza Esc.
- **Acceptance:** Test Vitest `lib/reminders/push.test.ts` weryfikuje bezpieczną obsługę w środowisku bez API przeglądarki, etyczną treść powiadomienia (brak produktów bankowych), domyślne 30-sekundowe opóźnienie, obsługę niestandardowego czasu oraz pełny cykl subskrypcji (`pnpm test` -> 60/60 zielone).
- **Needs from other lanes:** Osoba B może wywołać `<PushOptIn />` na koniec pierwszej pętli (po zapisaniu planu na ekranie G18 lub G23).
