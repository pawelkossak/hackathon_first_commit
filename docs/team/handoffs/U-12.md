# U-12 — Accessibility pass on the demo path

## Built
- **Skip Link & Main Content Landmark (`app/layout.tsx`):**
  - Added accessible skip link: `Przejdź do głównej zawartości` (`href="#main-content"`), visible upon keyboard focus.
  - Linked directly to `<main id="main-content" tabIndex={-1}>`.
- **Dialog Focus Trap & Escape Handling (`CashFlowPanel.tsx`, `WeekResolutionModal.tsx`, `FailureAndRewindModal.tsx`):**
  - Traps `Tab` / `Shift+Tab` focus cycles within active dialogs.
  - `Escape` key immediately closes or steps back in modals.
  - Initial focus lands on dialog primary action / close control; focus returns to trigger element on dismiss.
  - Added `role="tablist"` and `role="tab"` with `aria-selected` and `aria-controls` to Cash Flow tabs.
  - Made SVG forecast points keyboard focusable (`tabIndex={0}`) and selectable via `Enter` / `Space`.
- **Keyboard Navigation & Hit Targets (`WorldRoute.tsx`, `Hud.tsx`, `CardHand.tsx`, `Card.tsx`):**
  - Converted week nodes in `WorldRoute` to native `<button>` controls with `min-w-[44px] min-h-[44px]` hit targets and comprehensive `aria-label` descriptions.
  - Number keys `1`–`6` and `Escape` for selecting / clearing action cards.
  - Minimum 44px touch targets on HUD controls and modal action buttons.
- **Non-Color Reliance (GAME-EXPERIENCE-AND-NARRATION.md §11):**
  - Status messages, amounts, and critical warnings use explicit text labels and icons (`⚡`, `⚠️`, `✓`, `+`, `-`, `Deficyt`, `Płynność zachowana`).
  - Cash Flow plot lines distinguished by line styles (solid, dashed, dotted) and descriptive legends.
- **Tests (`components/play/accessibility.test.ts`):**
  - Automated tests covering keyboard card selection, route node aria-labels, non-color status formatting, and keyboard-driven rewind flow.
