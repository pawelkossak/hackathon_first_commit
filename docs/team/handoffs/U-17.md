# U-17 — Animations over art, reduced motion and performance budget

## Built
- **GPU-Accelerated CSS Animations (`app/globals.css`, `components/scenes/WorldRoute.tsx`):**
  - Added subtle floating plane animation (`animate-plane-float` with `will-change: transform`).
  - Added atmospheric storm glow (`animate-storm-glow` with `will-change: opacity, filter`).
  - Timings mapped directly to canonical tokens (`motionTimings` from `design/tokens.json`).
  - 60 fps target maintained on desktop and mobile by animating only composite properties (`transform`, `opacity`).
- **Reduced Motion Accessibility (`app/globals.css`, `lib/ui/motion.ts`):**
  - System setting `(prefers-reduced-motion: reduce)` disables all continuous animations, pulses, bounces, and pings.
  - Exported `usePrefersReducedMotion()` hook using React 18/19 `useSyncExternalStore` for reactive adaptation without cascading re-renders.
- **Tests (`components/ui/motion.test.ts`):**
  - Verified animation timings match design specifications (`select: 180ms`, `turn: 280ms`, `overlay: 180ms`, `starsEach: 250ms`).
  - Verified reduced motion fallback contracts.

## Acceptance
- `pnpm check` and `pnpm lane-check` green.
- 60 fps budget on desktop, animations disabled under reduced motion (satisfies U-17 acceptance).
