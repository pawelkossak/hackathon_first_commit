# U-02 — Placeholder theme and asset registry with Placeholder

## Built
- `app/globals.css`: Palette words and theme CSS variables from GAME-EXPERIENCE-AND-NARRATION.md §2:
  - `--purple-sky` (#2e1065) & `--purple-storm` (#581c87)
  - `--mint-plane` (#34d399) & `--mint-accent` (#10b981)
  - `--cream-panel` (#fffbeb), `--cream-panel-border` (#fef3c7), `--cream-text` (#1e293b)
  - `--gold-control` (#f59e0b) & `--gold-control-hover` (#d97706)
  - Body font size strictly set to `16px` (`font-size: 16px; line-height: 1.5;`) for AA readability.
  - `@media (prefers-reduced-motion: reduce)` accessibility rule disabling durations and transitions.
- `components/ui/Placeholder.tsx`: Sized placeholder component returning a styled container with asset id, width × height dimensions, label, dashed border, and category-derived colors (sky, weather, campaign, week, boss, player, client, bank, cfo, cat, action, event, crash).
- `lib/ui/assets.tsx`: Asset registry loaded from `design/contracts/runtime-sprites.json`:
  - `getAsset(id)`: returns exact dimensions, category, source and media paths for all 64 registered sprites.
  - `getAllAssetIds()`: returns all registered asset IDs.
  - `GameAsset`: Phase 1 component returning `<Placeholder>` with exact asset aspect ratio, seamlessly upgradable in Phase 2 to `<img>` from `/media/`.
- `lib/ui/assets.test.ts`: Vitest test verifying all 64 sprites and fallback dimensions.
