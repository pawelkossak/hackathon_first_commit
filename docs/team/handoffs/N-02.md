# Handoff N-02: Number guardrail for generated text

- **Built:** Strażnik liczb `lib/ai/guardrail.ts` oraz publiczne API `lib/ai/index.ts`. Strażnik wyciąga liczby z generowanego tekstu (w tym liczby formatowane ze spacjami, ujemne, ułamki i procenty), pobiera dozwolone liczby z silnika (`collectEngineNumbers`) i odrzuca wypowiedzi zawierające liczby spoza silnika (`validateNumberGuardrail`, `applyGuardrailOrFallback`).
- **Acceptance:** Test Vitest `lib/ai/guardrail.test.ts` weryfikuje odrzucenie zdania z liczbą niewywodzącą się z silnika, akceptację zdań z liczbami silnikowymi lub bez liczb, oraz podmianę na tekst awaryjny (`pnpm test` -> 29/29 zielone).
- **Needs from other lanes:** None.
- **Open:** None.
