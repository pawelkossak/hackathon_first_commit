# U-15 — Mobile landscape (844×390) and rotate prompt

## Built
- **Rotate Device Prompt (`components/ui/RotatePrompt.tsx`, `app/layout.tsx`):**
  - Activated when a mobile device is oriented in portrait mode (`@media (orientation: portrait) and (max-width: 768px)`).
  - Displays canonical Polish prompt from copy deck: *„Obróć telefon, lecimy w poziomie.”*
  - Includes dismiss/fallback button with accessible copy: *„Kontynuuj w widoku tekstowym”*, allowing non-trapping continuation for accessibility or users unable to rotate.
- **Mobile Landscape Layout Adaptations (`app/globals.css`, `components/play/Hud.tsx`, `components/play/CardHand.tsx`):**
  - Designed for key mobile landscape viewports: 844×390 (iPhone 12/13/14), 812×375 (iPhone X/XS), 932×430 (iPhone 14/15 Pro Max) without horizontal body scrolling.
  - Interactive touch targets maintained at ≥ 44×44 CSS pixels.
  - Cards arranged in responsive tray format for landscape touch devices.
- **Tests (`components/ui/mobile-landscape.test.ts`):**
  - Verified canonical copy strings, touch target sizing, and landscape viewport constraints.
