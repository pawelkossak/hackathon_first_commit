---
description: Open the running game in the browser, compare the screen with its layout and walk the demo path; report what breaks.
---

1. Make sure `pnpm dev` is running and open http://localhost:3000.
2. Set the viewport to 1440×900 (and 844×390 when the task mentions mobile landscape).
3. For the screen of the current task: compare it with its description in `docs/specification/GAME-EXPERIENCE-AND-NARRATION.md` §6 and §17 (or its image in `design/layouts/` once it exists) and note differences in position, size, text and colour.
4. Walk the demo path of `docs/specification/GAME-DESIGN.md` §9 as far as it is built: once fast like a juror, once only with the keyboard (Tab, Enter, Escape, keys 1–6).
5. Check on every screen: text ≥ 16 px, visible focus, no meaning by colour only, captions under voice, every amount equal to the specification, the factoring card labelled as a scenario.
6. Take a screenshot of every problem. Write the list into the handoff of the current task (or tell the person if no task is in progress).
